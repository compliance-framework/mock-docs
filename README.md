# mock-docs

A sandbox copy of [compliance-framework/docs](https://github.com/compliance-framework/docs) used to develop and test the [CCF Factory](https://github.com/compliance-framework/factory).

The factory's **dev** RuleSets target this repo (mock release trains, fake versions, the i18n epic) before anything touches the real docs. Content here is not authoritative; see https://compliance-framework.github.io/docs/ for the real documentation.

It gets seeded from `docs` by task DOC-S2-T01 (see `design/workstreams/definitions.md` in the factory repo).
